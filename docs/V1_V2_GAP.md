# V1 → V2 차이 분석

작성일: 2026-09-08

## 목표 차이

V1은 사용자가 바로 실행하는 도구와 게임 모음입니다. V2는 검색·숏폼에서 들어온 사용자가 콘텐츠를 읽고 참여하며, 결과가 누적되어 다시 발견되는 콘텐츠 플랫폼을 목표로 합니다. 가장 큰 차이는 화면 수가 아니라 **공개 콘텐츠 단위, 영속 데이터, 운영 체계**입니다.

## 기능 격차

| 역량 | V1 | V2 P0 목표 | 격차 | 처리 |
| --- | --- | --- | --- | --- |
| 홈 피드 | 정적 기능 카드 | 인기·신규·카테고리 콘텐츠 | 큼 | DB 기반 서버 렌더링 |
| VS | 없음 | 1:1 선택과 누적 비율 | 전부 없음 | 신규 |
| 월드컵 | 브라우저 개인 플레이 | 공개 16/32강, 누적 선택 | 저장·집계 없음 | 로직 일부 이관 |
| 결과·랭킹 | 개인 세션 순위 | 전체·기간·카테고리 랭킹 | 전부 없음 | 신규 |
| 분류 | 제한적 정적 카테고리 | 카테고리·태그·검색 | 큼 | 신규 스키마와 검색 |
| 공유 | URL에 게임 데이터 포함 | 고정 상세 URL과 OG 카드 | 큼 | 신규 |
| CMS | 없음 | 작성·미리보기·발행·숨김 | 전부 없음 | 신규 |
| 익명 세션 | 브라우저 상태 | 서버 검증 세션 | 전부 없음 | 신규 |
| 중복 투표 | 없음 | 세션·콘텐츠 단위 완화 | 전부 없음 | 신규 |
| 분석 | 없음 | 유입→시작→완료→공유 | 전부 없음 | 신규 |
| 신고 | 없음 | 접수·검토·처리 | 전부 없음 | 신규 |
| SEO | CSR 후 메타 변경 | 콘텐츠별 서버 HTML | 구조적 격차 | Next.js 전환 |
| 광고 안전 | 일부 화면 광고 제거 | 콘텐츠/동의/노출 규칙 | 운영 체계 없음 | 출시 게이트 |

## 데이터 격차

V2에는 최소 다음 개체가 필요합니다.

- `content`: 제목, 슬러그, 유형, 설명, 공개 상태, 검수 상태, 공개일
- `candidate`: 콘텐츠별 후보, 순서, 이미지, 대체 텍스트, 출처·권리 메모
- `category`, `tag`, `content_tag`: 탐색과 검색 분류
- `vote_session`: 익명 세션 해시, 생성·만료 시각, 위험 신호
- `vote`: 콘텐츠, 대결, 선택 후보, 세션, 시각
- `content_stats`, `candidate_stats`: 빠른 랭킹 조회용 집계
- `report`: 신고 사유, 상태, 처리자와 처리 시각
- `admin_user`, `audit_log`: 운영 권한과 변경 이력

V1의 `quizSessions`와 `gameSession`은 이 모델을 대신할 수 없으므로 마이그레이션 대상이 아닙니다.

## 콘텐츠 격차

AdSense 검토 관점에서도 기능 버튼만 있는 화면보다 독립적으로 읽을 가치가 있는 상세 페이지가 필요합니다. 각 공개 콘텐츠는 최소한 다음을 가져야 합니다.

- 고유한 제목과 요약
- 주제·선정 기준에 대한 편집 설명
- 후보별 이름, 이미지 대체 텍스트, 필요한 출처 정보
- 참여 방법과 결과 해석
- 관련 콘텐츠 연결
- 신고와 문의 진입점

정확한 글자 수를 기계적으로 맞추는 방식은 기준으로 삼지 않습니다. 중복 설명이나 자동 생성 문구보다 사용자가 실제로 판단하는 데 필요한 고유 정보를 우선합니다.

## 운영 격차

| 항목 | 현재 | P0 완료 조건 |
| --- | --- | --- |
| 게시 | 코드 배포 | 관리자 초안→검수→발행 |
| 수정 | 코드 변경 | CMS 수정 및 감사 로그 |
| 숨김 | 기능 없음 | 즉시 비공개 및 캐시 갱신 |
| 신고 | 기능 없음 | 사용자 접수와 관리자 처리 |
| 통계 | 기능 없음 | 핵심 퍼널과 콘텐츠 지표 |
| 복구 | 메모리/브라우저 | DB 백업과 이관 롤백 |
| 광고 | 화면 내 직접 삽입 | 중앙 정책 컴포넌트와 동의 상태 |

## P0 완료 기준

V2 P0는 다음 조건을 모두 만족할 때 완료로 봅니다.

1. 관리자가 VS 또는 월드컵 콘텐츠를 작성하고 발행할 수 있다.
2. 공개 상세 페이지가 자바스크립트 없이도 제목·설명·후보를 제공한다.
3. 익명 사용자의 선택이 서버에 저장되고 중복이 완화된다.
4. 결과와 랭킹이 실제 집계에서 생성된다.
5. 카테고리·태그·검색·관련 콘텐츠로 탐색할 수 있다.
6. 공유 URL과 OG 이미지가 콘텐츠별로 올바르다.
7. 신고, 분석, 오류 추적, 백업 절차가 있다.
8. 콘텐츠가 없는 진행·이동·알림 화면에는 광고 슬롯이 없다.
9. 공개 전 품질·권리·정책 체크리스트를 통과한다.
