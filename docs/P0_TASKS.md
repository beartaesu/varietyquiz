- 마이그레이션 롤백 대신 안전한 후속 수정 절차가 문서화된다.

## P0-03 콘텐츠 읽기 서비스와 샘플 이관

상태: `ready`

목표: 발행된 콘텐츠만 안정적으로 읽고, 이관 도구의 안전 기준을 증명한다.

범위:

- 콘텐츠 상세·목록·분류 repository/service
- 정렬과 페이지네이션
- `--dry-run` 기본의 샘플 이관 명령

완료 조건:

- 이관 전후 건수와 표본을 자동 대조한다.
- V1 연예인 JSON은 권리 승인 전 자동 이관하지 않는다.

선행 작업: P0-02.

## P0-05 VS 익명 투표와 집계

상태: `ready`

목표: 로그인 없이 참여하되 단순 반복 투표를 완화하고 신뢰할 수 있는 누적 결과를 제공한다.

범위:

- 서명된 익명 세션 쿠키
- 서버 측 선택 검증과 트랜잭션
- 세션·콘텐츠·대결 유일 키
- 속도 제한과 위험 신호
- 후보별 득표와 비율 집계
- 시작·선택·완료·공유 분석 이벤트

완료 조건:

- 정상 사용자는 한 번 선택하고 즉시 결과를 본다.
- 같은 세션의 동일 대결 재투표는 집계되지 않는다.
- 동시 요청에서도 원본 투표와 집계가 불일치하지 않는다.
- 원본 투표에서 집계를 재생성한 값이 동일하다.
- IP 원문과 세션 토큰 원문을 DB에 저장하지 않는다.

선행 작업: P0-02, P0-04.
